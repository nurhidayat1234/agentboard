Cara kerja

  1. Creator (pemegang Agent ID) buat task dan kunci reward BNB di contract.
  2. Claimer (pemegang Agent ID lain) klaim task.
  3. Claimer submit bukti pengerjaan.
  4. Creator setujui → reward cair ke claimer. Batal sebelum diklaim → refund ke creator.
